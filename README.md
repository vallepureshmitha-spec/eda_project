# eda_project
# Exploratory Data Analysis Pipeline

## Project Scope
This project establishes a standardized framework for Exploratory Data Analysis (EDA). The main program ingests unrefined data collections, computes central tendency measurements, uncovers data skews, evaluates correlation boundaries, and formats these insights into a structured four-panel diagnostic visualization dashboard.
